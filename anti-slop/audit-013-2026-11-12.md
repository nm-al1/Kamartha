## Scoped gate and purpose

- R-03 PASS for exercised scope: review tests at text 200% on 320x568 and 800x360;
  actual browser upload/review at 320x568, 390x844, 800x360. Filename and summary
  wrap in inspected preview-320.png. Cards group actual imported records; the
  entire review scrolls so confirmation does not cover content.
- R-17/R-38 PASS for exercised scope: preview values come from the server's
  parser and reconciliation. Static browser data is explicitly synthetic and
  never written to primary backend. No invented production counts or identities.
- R-26/R-27 PASS for exercised scope: native file chooser, loading/error, oversize
  rejection without upload, per-row errors, blocked invalid import, explicit
  confirmation, retry, and return to Data awal are exercised by widget/browser
  tests. New/same data is labelled; invalid data cannot be confirmed.
- R-35 PASS for exercised scope: 174 Flutter tests, clean analyzer, successful
  release build; separate real isolated-PostgreSQL and intercepted-browser suites.
  See docs/testing/opening-excel-import-2026-11-12.md for exact evidence and limits.
- Purpose: separate preview prevents accidental financial imports; confirmation
  records consent to draft creation, not finalization; existing data is never
  overwritten; text labels accompany statuses and errors rather than color alone.
