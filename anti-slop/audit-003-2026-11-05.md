# UI & Layout Anti-Slop Audit: Stage Mobile Responsiveness

Date: 2026-11-05. Scope: All 28 mobile operational screens on page `Design.md · Kamartha UI` in `design/kamartha-design-responsive.figcraft`.
Method: FigCraft MCP node inspection, layout tree depth analysis, token validation, and full horizontal overflow checks.

## Anti-Slop Principles Applied

1. **Context-First & Anti-Generic**: Preserve real kos-kosan operational workflows (ENERGY 1 / RHYTHM 1 / MOTION 1). No decorative marketing fluff, no invented badges, no faked dashboard metrics.
2. **Elimination of Nested Padding Slop**: Strict adherence to the standard single 16 px screen margin. No double-padding nesting that squeezes content into narrow columns.
3. **Design Token Conformance**:
   - Typography: 16 px body/input, 14 px metadata, 24 px title, 30 px primary room header.
   - Corner Radius: 12 px inputs, 16 px cards/information groups, 24 px filled action buttons, pill chips.
   - Spacing: 4, 8, 12, 16, 24, 32 px token scale.
   - Touch Targets: Minimum 48 × 48 px.

## Findings & Resolutions

1. **CRITICAL, Nested Double-Padding on `HOME-01` (Beranda):**
   - *Finding*: `Aliran konten` (Node 3289) already applied 16 px horizontal padding. However, child containers `Hero dan panel hunian` (Node 3290), `Sapaan · aliran` (Node 3291), and `Tindak lanjut · aliran` (Node 3297) each applied an additional 16 px horizontal padding. This squished all content cards (`Panel pencarian dan hunian`, `Kelompok tagihan`, `Pencatatan cepat`) down to 296 px width with 32 px outer margins on each side.
   - *Resolution*: Removed redundant horizontal padding from `3290`, `3291`, and `3297` (`padding: [32, 0, 16, 0]`, `[0, 0, 0, 0]`, and `[0, 0, 24, 0]`). All cards now expand cleanly to 328 px (`fill`), matching the 16 px compact Android margin across all other 27 screens.

2. **LOW, Non-Token Corner Radius on `HOME-01` & `WA-01`:**
   - *Finding*: `Panel pencarian dan hunian` (Node 1220) had `cornerRadius: 20.0` instead of the tokenized `16.0`. Floating dialog `Panel pesan` (Node 1156) also had `cornerRadius: 20.0`.
   - *Resolution*: Updated both to `16.0 px` adhering to `docs/design.md:46`.

3. **LOW, Inconsistent Bottom Sheet & Dialog Horizontal Margins:**
   - *Finding*: `INV-03` (`Panel filter · aliran`, Node 3318) and `WA-01` (`Viewport`, Node 3313) used 20 px padding instead of 16 px.
   - *Resolution*: Normalized horizontal padding to 16 px.

4. **MEDIUM, Displaced Filter Icon on `INV-01` (Daftar tagihan):**
   - *Finding*: `Ikon filter` (Node 1494) was placed as the first child of `Aliran konten`, causing it to float on an awkward separate line between the header and the search field. In the original design, it was positioned in the header alongside the screen title.
   - *Resolution*: Reparented `Ikon filter` into `Header · responsif` (Node 2848). Because `Judul dan konteks` uses `horizontal: fill`, the filter icon now sits neatly on the top-right of the header next to the title `Tagihan`.

5. **HIGH, Rekonstruksi Kartu Ringkasan Kas pada `REPORT-01` (Laporan kas):**
   - *Masalah*: Kartu `Ringkasan kas` (Node 1813) sebelumnya dipecah secara horizontal tidak beraturan (baris 1: label Pemasukan & Pengeluaran; baris 2: nilai nominal; baris 3: garis pemisah terpotong di kiri sepanjang 96 px bersanding canggung dengan teks "Selisih kas" dan nominal). Label dan nominal tidak terikat per kolom sehingga letaknya bergeser miring, dan garis pemisah tidak membentang penuh.
   - *Perbaikan*: Direkonstruksi secara modular menggunakan Auto Layout anti-slop:
     1. **Baris KPI Atas**: Dibagi menjadi dua kolom independen (`Kolom pemasukan` dan `Kolom pengeluaran`, masing-masing `fill width 50%`) yang dipisahkan oleh garis vertikal halus (`1x42 px`, `#EEF2F6`). Setiap kolom mengikat label dan nominalnya secara vertikal sehingga tidak akan pernah meleset.
     2. **Pemisah Penuh**: Garis horizontal pembatas (`1x294 px`, `#EEF2F6`) membentang penuh di tengah kartu.
     3. **Baris Selisih Bersih Bawah**: Menggunakan layout `Lajur selisih kas` dengan alignment `spaceBetween`. Label `"Selisih kas (surplus)"` di sisi kiri, dan nominal `Rp150.000` di sisi kanan dengan warna emerald green `#08964D` (menegaskan status surplus positif).

6. **SYSTEM-WIDE, Master Components & Board Alignment:**
   - Updated `Bottom Navigation / Kamartha` master variants on `Components · Kamartha` (Page 2276) to width `360.0 px`.
   - Updated all 29 screen title board labels on Page 400 from `390.0 px` to `360.0 px` to line up with the mobile screens.

7. **VERIFICATION, Horizontal Overflow & Token Audit:**
   - Evaluated all 28 screens at 360 px width.
   - *Result*: **0 horizontal overflows**. All cards, inputs, and buttons adapt fluidly (`fill width`, `hug height`).
   - 100% token conformance on corner radiuses (inputs 12, cards 16, buttons 24) and safe areas (top 40, bottom 24).
